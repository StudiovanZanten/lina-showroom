# LINA showroom

Verkoopsite van LINA voor franchiseorganisaties.
Nederlands op linanextgeneration.nl, Engels op linanextgeneration.com (en /en/).

* Alle teksten (NL en EN) staan in `build.mjs`.
* Opmaak in `src/stijl.css`, beweging in `src/site.js`.
* Bouwen: `node build.mjs`, de site komt in `dist/`.
* Vercel bouwt vanzelf bij elke push naar main.

Alle namen en getallen in de voorbeelden zijn verzonnen.
